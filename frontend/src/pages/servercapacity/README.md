# Ubuntu 직접 용량 조회 화면

2026-11-14 기준. `ServerCapacityPage.jsx`의 **지금 조회** 버튼이 `GET /api/server-capacity/host`를 호출합니다.

- 자동 조회·주기 수집 없이 클릭할 때만 Ubuntu에 직접 측정을 요청합니다.
- CPU·메모리·루트 디스크 사용률과 이번 요청의 측정 시각을 카드로 표시합니다.
- 중복 클릭 방지, 화면 이탈 시 요청 취소, 실패 시 이전 결과임을 명시합니다.
- 로그인 인증을 유지합니다. 호스트 연결 실패 503, 과부하 429를 안내합니다.
- Ubuntu VM 전체 기준이며 Windows 전체·컨테이너 한도·다른 마운트는 포함하지 않습니다.
